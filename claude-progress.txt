## 実行中
- feature/google-sign-in(「Google でサインイン」): ログイン画面のボタン。連携済みの Google だけが入れる(未連携は Web が断り、赤字の案内。ユーザーは作られない)。expoClient は戻りのリンクを捨てるので、signIn.social を disableRedirect で呼び、expo-authorization-proxy を自分で開き(src/lib/sign-in-google.ts)、戻りのリンクを acceptSignInLink(S3 のコード交換 + PKCE)に渡す。state と challenge の発行は startRequest(sign-in-link.ts)に切り出した。同じリンクの二重到着は、コードで見分けて無視する。OAuth の state Cookie は findOAuthState(sign-in-rules.ts、テスト付き)
  - Android の開発では、Web への接続先を localhost にした(config.ts)。Google の戻り先が localhost:3000 で、Cookie はホストごとのため、10.0.2.2 だと `state_security_mismatch` になる。`adb reverse tcp:3000 tcp:3000` が要る(Go は 10.0.2.2 のまま)
  - 端末で確認済み: iOS で連携とサインイン。Android でサインイン、Unlink、Link。未連携の Google は拒否され、キャンセルは元の画面に戻る。未確認: 実機
  - Web は変更なし(main の PR #27 で足りる)

- アプリの名前と id(2026-10-26): name は Auth Practice、slug は auth-practice、bundle id と package は com.shu915.authpractice。変えたので、入っている古いアプリとは別のアプリになる(新しく入れ直し、セッションも入り直し)
