## 本番の前に必須
- **S3**: カスタムスキーム(betterauthmulti://)は他のアプリも登録できる。さらに Web の本番の trustedOrigins が無条件にこのスキームを含むので、モバイルを使わない人のメール宛てにも、攻撃者が callbackURL 付きのリンクを送らせられる。1 回限りのコード交換(Cookie を URL に載せない。短命のコードを、アプリが verifier 付きで引き換える)か、セッションを URL に載せない Universal Links / App Links にする
- Go の本番の DB にマイグレーション 00002(deleted_users)を当ててから、Go を出す(逆だと PUT /me/profile と DELETE /me が 500)
- app.json の com.anonymous.mobile を変える(ストア審査と App Links の設定で詰まる)
- 本番ビルドは EXPO_PUBLIC_WEB_URL と EXPO_PUBLIC_API_URL(https)が必須。EXPO_PUBLIC_ の値はアプリに入って誰でも読めるので、秘密は入れない
