## 実行中
- feature/google-link(Google の連携と解除。「Google でサインイン」は次の PR): プロフィール画面の「Sign-in methods」(src/components/sign-in-methods.tsx)。メールのリンクは常に有効、Google は連携済みなら Unlink(確認ダイアログ付き)、なければ Link Google。連携は authClient.linkSocial(アプリ内ブラウザ)。戻りのリンクには何も入らないので、連携できたかは一覧(listAccounts)を最大 4 回(1.5 秒おき)読み直して判断する(src/lib/google-link.ts、判断は linked-accounts-rules.ts)。5 分ルール(SESSION_NOT_FRESH)は「サインインし直して、すぐに」の案内、401 はサインアウト。連携・解除中は退会と Sign out を押せない。judgeLink は、state のないリンク(Google の連携から戻ったときのリンクなど)を、error や cookie が付いていても無視する(「Sign-in failed」を出さない)。Vitest 117 件、evaluator 合格
  - 端末で確認済み: iOS で連携と解除、5 分ルールの案内。Android でキャンセル(連携されなかったときの案内)。Android の連携は、Web に通知メールが出たが、アプリの表示は直す前の状態だった。**未確認: Android で連携と解除を通して、表示が「Google: linked」と「not linked」に変わること。iOS でのキャンセル(Google のログインが残っていて、画面が出ない)**
  - **マージの順序: Web の PR #27(セッションを作らない戻りでは、コードもエラーも付けない)が先**
  - 1 つの Google アカウントは、1 人のユーザーにしか連携できない(別のユーザーに連携済みだと断られる。Drizzle Studio の account テーブルで確認できる)
- feature/s3-code-exchange(レビューの S3): マジックリンクで戻るリンクに、セッションを載せない。1 回限りのコード + PKCE にした
  - Web(ブランチ feature/mobile-code-exchange、コミット済み 1b49b84。PR はまだ): mobileCodeExchange() が、expo() が付けた ?cookie= を取り除いて ?code= にする。POST /api/mobile/exchange {code, verifier} でセッションに引き換える。コードは 1 回で使い切り、60 秒で失効
  - モバイル(未コミット): verifier(32 バイトのランダム)と challenge(SHA-256)を作り、callbackURL に cc を付けて要求する。戻ってきたリンクの code を、state を照合してから、verifier と一緒に引き換える(src/lib/exchange-code.ts、sign-in-link.ts、sign-in-rules.ts の Pending に verifier)。?cookie= 付きのリンクは拒否する。+native-intent.ts は code もルーターに渡さない。リンクの判断(cookie 付き・error 付きは拒否、code がなければ無視、形の検査)は judgeLink に切り出してテストした。Vitest 104 件、tsc、lint、expo export は通る。evaluator は合格
  - 端末で確認済み: iOS でログインが通る(Web に `POST /api/mobile/exchange 200`)。同じリンクの再利用は失敗する。Android も、JS を再読み込みしたあと(古い JS だと cc が付かず、Web が missing_challenge で拒否する)ログインできた。**未確認: Web の「暗号化して保存」の変更のあと、もう一度のログイン**。Web の dev サーバーは feature/mobile-code-exchange で動かす
  - デプロイの順序: 古いモバイルは、Web の新しい版でログインできなくなる(cc を送らない)。開発中は問題ない。本番は、モバイルと Web を同時に出す
  - 残る限界: 攻撃者が自分で cc を付けたログインメールを被害者に送らせ、被害者の端末に攻撃者のアプリがある場合は、コードを取られる。Universal Links / App Links が要る(ドメインとストアの設定が決まってから)
